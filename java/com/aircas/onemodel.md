- 2026-05-19：摊开二维底座菜单，新增“绘制设备点”入口，支持选择设备图层后直接进入地图点绘制模式。
- 2026-05-19：补充区域经纬度范围提示，新增“绘制区域”入口，支持地图矩形绘制后自动写入区域范围。
- 2026-05-19：新建工程默认定位到源码工程 data 目录，目录选择器自动回退到最近存在的父目录。
- 2026-05-19：整理二维底座菜单，将区域范围和设备点的输入坐标/手动绘制合并为下拉入口。
- 2026-05-19：完善“选择设备连线”，连接写入后刷新地图并设置连接线样式，设备坐标支持从点几何兜底读取。
